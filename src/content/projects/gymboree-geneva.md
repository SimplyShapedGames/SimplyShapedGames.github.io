## Keeping the details in good shape.

Work on Gymboree Geneva's existing WordPress website covers its English and French pages. The contribution is ongoing content care, responsive presentation and targeted technical improvements—not original authorship of the whole site.

## Small details that make a site work

- **Responsive banners:** refine the framing across screen sizes, with a dedicated WordPress integration to preserve the styling when unused CSS is removed by the cache system.
- **Current information:** remove expired Geneva campaigns and correct public address and map links.
- **Working page routes:** repair the French birthday-page redirect so visitors reach the intended page.
- **Bilingual upkeep:** maintain content and presentation across the English and French Geneva pages.

These changes build on the venue's existing WordPress website and brand. The work shown here is specific to **Geneva**.
